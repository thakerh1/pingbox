How it works

Three steps. No signup.

01

Paste or upload

Type one email, paste a list, or drop a CSV file. Pingbox handles any format automatically.

02

We ping the server

Pingbox checks syntax, DNS, MX records, and does a real SMTP handshake with the mail server.

03

Download your clean list

Get a confidence score for every email. Export valid-only as CSV, ready for your next campaign.

What Pingbox checks

Six layers of verification

🔤

Syntax

Catches typos, missing @, bad characters, and malformed addresses instantly.

🌐

Domain lookup

Confirms the domain actually exists via live DNS resolution.

📬

MX record check

Pings the real mail server to confirm it can receive email at all.

🤝

SMTP handshake

Goes one step further and asks the server directly if this specific mailbox exists.

🗑️

Disposable detection

Flags 2,000+ throwaway inbox providers like Mailinator and YOPMail.

🎯

Role-based flags

Detects shared inboxes like info@ and support@ that hurt open rates.
